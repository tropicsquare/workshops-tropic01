# TROPIC01 Workshops

This repository contains workshop materials for programming the TROPIC01 chip—a secure element designed for cryptographic operations.

Each workshop focuses on practical implementations using TROPIC01 in different contexts and environments.

## Workshops

- [39C3](/39C3/) - Programming TROPIC01 on the CDC Badge Nametag
- [IF26](/IF26/) - Introductory workshop on TROPIC01 (CZ only)

## About TROPIC01

TROPIC01 is a secure cryptographic chip supporting various cryptographic operations including ECDSA, EdDSA, MAC And Destroy and secure memory.

Learn more at [tropicsquare.com](https://www.tropicsquare.com/)
